Télécharger l'application
  1. Téléchargez le fichier app-release.apk (lien ci-dessus, ou via github.com/joynagassi-cyber/luminap/releases).
  2. Dézippez/ouvrez le fichier — Android propose l'installation.
  3. Si demandé, autorisez « Installer des applications inconnues » pour cette source, puis « Installer ».
