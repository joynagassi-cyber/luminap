📐 Wireframe Schema

Structure du Dashboard

1 Top Header (Logo + Notifications + Settings)
2 Hero Card (Solde principal + Entrées/Sorties)
3 Quick Stats (En attente, Événements, Groupes)
4 Caisses Grid (Liste des caisses groupe)
5 Actions Rapides (Grid 2x2 ou 4 colonnes)
6 Dernières Transactions (Liste scrollable)
7 FAB Button (Nouvelle transaction)
8 Bottom Navigation (4 items + Plus)

Responsive Breakpoints

Mobile (375px)

Single column, cards full-width, 2-col grid for actions

Tablet (768px)

Max-width container centered, 2-col caisses grid

Desktop (1024px+)

Same as tablet, hover effects, larger touch targets

💡 Ma Recommandation

Pour Lumina, je recommande la Variante A (Modern Cards) avec les ajustements suivants:

  • → Hero card avec gradient orange pour mettre en avant le solde principal
  • → Stats rapides en grille 3 colonnes pour un coup d'œil immédiat
  • → Actions rapides en grid 4 pour un accès direct aux fonctions principales
  • → Caisses en cards compactes avec solde et tendance
