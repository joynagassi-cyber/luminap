# 2026-10-23 — Session stabilisation Lumina (clôture)

## Découvertes coûteuses à réapprendre

- **Cypress dans cet environnement** : lancé au PREMIER PLAN, Electron meurt
  en SIGSEGV (`exit 139`, log vide). Il FAUT `setsid nohup … &` + polling du
  fichier de log. Vérifier que le serveur Vite (`127.0.0.1:8080`) ET `Xvfb :99`
  tournent : leur disparition produit exactement le même `exit 139` muet.
- **`Xvfb` peut disparaître de l'image** en cours de session. Réinstaller :
  `sudo apt-get update && sudo apt-get install -y xvfb` (le paquet n'est pas
  dans l'index apt tant qu'`update` n'a pas tourné). Supprimer `/tmp/.X99-lock`.
- **Prettier peut rester suspendu** (`Tl` dans `ps`) et bloquer un shell —
  le tuer par PID plutôt que d'attendre.
- **Pages Ionic** : toutes les pages visitées restent montées dans
  `ion-router-outlet` et masquées. `ion-app` porte AUSSI `.ion-page` : un
  sélecteur global `cy.contains(...)` peut tomber sur une page cachée →
  faux « not visible ». Utiliser `activePage()` / `activePageShouldContain()`
  (`cypress/support/view.ts`) ; le helper accepte désormais une RegExp.
- **Ionic** : `ion-select-option` est dans le light DOM mais `display:none`
  tant que le popover n'est pas ouvert → cliquer l'HÔTE `ion-select`, puis
  chercher l'option dans `ion-popover` (monté sur `body`).
- **Cypress + test runner** : le corps du test s'exécute SYNCHRONE ; les URLs
  interpolées hors `cy.then()` sont construites avec des variables vides
  (→ 401). Toujours construire les requêtes dans un `cy.then()`.
