## Pièges appris
- **Test env** : la suite exige `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY`
  (sinon `src/lib/auth.ts` lève à l'import → ~100 fichiers « failed »). Créer un
  `.env.local` (gitignoré) avec des valeurs factices suffit pour lancer TOUTE la
  suite en local (2191 → 2210 tests). Avant, je croyais ces échecs
  « préexistants » : ils venaient uniquement de l'env manquant.
- **Bug réel attrapé** : `ObservabilityBridge` (importé, appelle `useLocation()`)
  avait été monté AU-DESSUS de `<IonReactRouter>` → panne totale (même classe que
  l'incident PR15). La garde `router-context-guard` ne le voyait PAS car elle
  n'analysait que les composants DÉCLARÉS dans App.tsx. **Durcie** pour résoudre
  les imports locaux et vérifier aussi les composants IMPORTÉS (non-vacuité
  prouvée par mutation). Règle : tout composant à hook de Router DOIT être rendu
  sous `<IonReactRouter>`.
- **Edge functions** : `supabase functions deploy` via npx met >120 s à installer
  le CLI (timeout) → utiliser le MCP `deploy_edge_function` (immédiat).
- `Deno.env.get("SUPABASE_SERVICE_ROLE_KEY")` : le runtime injecte déjà les clés
  Supabase standard (SUPABASE_URL, SERVICE_ROLE_KEY, PUBLISHABLE_KEYS…) — pas
  besoin de les poser en secret.
- Le dépôt est **PUBLIC** : tout ce qui entre dans une Issue est publié → le
  rapport est expurgé côté client (`redact` + `scrubIdentities`) AVANT envoi.
- Gardes mémoire du repo : `no-cjk-strings`, `perf-budget`, `coverage-matrix`
  (toute réf `V:`/`C:`/`SQL:` doit pointer un fichier réel → mise à jour de
  `docs/agent/COVERAGE_MATRIX.md` obligatoire quand on cite un nouveau test).

## Observabilité → GitHub Issues : voie pré-login anonyme (branche `feat/observability-github-issues`)

- **Défaut corrigé (R145)** : `report-error` exigeait un JWT → tout incident
  AVANT connexion était perdu (précisément le plus utile). Corrigé : la fonction
  passe en `verify_jwt:false`, vérifie l'appelant elle-même (`auth.getUser`) et
  distingue 2 voies : authentifié (20/h, bucket `user:<uuid>`) vs anonyme

  retombe sur l'anonyme (pas de contournement du plafond).

  grant service_role seul) + RPC `register_anonymous_report` SECURITY DEFINER,

  en vitest 5 (« Failed to load custom Reporter from basic »). Utiliser
