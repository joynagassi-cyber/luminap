# Règle projet — TickTick : source de vérité du planning

**Toujours utiliser TickTick pour le planning**, dans tous les projets où le MCP TickTick est disponible.

## Règles

1. **Avant tout travail de planification ou d'exécution multi-étapes** : s'assurer que la structure TickTick existe (projet, tâches, sous-tâches, dates, priorités, tags). Si elle n'existe pas, la créer **avant** de commencer.
2. **À chaque CHECKPOINT / fin de phase** : mettre TickTick à jour — cocher les sous-tâches terminées, ajouter les liens de PR en commentaire, créer les tâches « Bug » découvertes.
3. **Ne jamais** simuler la planification dans un fichier local si TickTick est accessible : le projet TickTick est la seule source de vérité.
4. **Ne jamais** supprimer une tâche ou un projet existant ; compléter l'existant plutôt que recréer.
5. **Ne pas cocher une tâche comme terminée** avant que tous ses critères de sortie soient validés.
6. Si le MCP TickTick n'est pas connecté ou échoue : **STOP et le signaler** au lieu de continuer sans plan.
